# Battery Thermal Management System (BTMS)

## Objective
Develop a thermal management model for a battery system to maintain optimal operating temperature.

## Description
This project focuses on modeling and simulating the thermal behavior of a battery pack and implementing control strategies to regulate temperature.

## Features
- Battery thermal model
- Heat generation and dissipation
- Cooling system simulation
- Temperature control strategy

## Tools
- MATLAB
- Simulink

## Structure
- model/ → Simulink models
- scripts/ → MATLAB scripts
- images/ → screenshots and plots

Work in progress
